# SMARTHIRE-AI-Intelligent-Resume-Short-lister
SmartHire AI is an intelligent resume shortlisting system designed to simplify the recruitment process. The application analyzes candidate resumes against specified job requirements and helps identify the most suitable candidates based on their skills, qualifications, and experience.

The system reduces manual effort in the initial screening process and provides a faster way to shortlist relevant candidates.

✨ Features
Upload and analyze candidate resumes
Enter job requirements for a particular position
Compare candidate profiles with job requirements
Identify relevant skills and qualifications
Generate candidate suitability results
Rank candidates based on their relevance
Simple and user-friendly interface
